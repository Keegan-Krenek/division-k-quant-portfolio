# SQL Proto-Database

This folder contains the SQL schema, ERD, and engine-level tables used to support structural market research.

## What This Module Does
- Defines the database structure for engine maps, actors, spikes, cycles, and outcomes.
- Provides dependency-ordered SQL files for clean initialization.
- Stores structured research data for analysis and automation.

## Contents
- ERD diagram  
- SQL schema files  
- Table definitions  
- Dependency order notes  

## How to Use This Folder
Review the ERD first, then follow the dependency order when creating tables.  
This module is the foundation for future automation and data ingestion.
