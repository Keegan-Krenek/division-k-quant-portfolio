# Master Schema (20-Layer Structural Market Model)

This folder contains the full 20-layer structural schema used to map synthetic market engine behavior. Each layer represents a specific component of market structure, engine motion, or actor influence.

## What This Module Does
- Breaks the market into repeatable structural parts.
- Tracks engine cycles, movement families, and actor behavior.
- Provides the foundation for structural trading and cycle prediction.
- Organizes research into a consistent, scalable framework.

## Folder Structure Overview
Each subfolder represents one layer of the schema:
- Layer 1–3: Market logs, daily logs, trade logs  
- Layer 4: Engine maps, movement families, actor registry  
- Layer 5–6: Memory taps, liquidation events, synthetic spikes  
- Candle layers: 1m, 5m, 15m, 1h tracking  
- Additional layers: spike datasets, cycle timing, structural outcomes

## How to Use This Folder
Start at Layer 1 and move downward.  
Each layer builds on the previous one and contributes to the full engine model.

This folder is the “brain” of the entire research system.
