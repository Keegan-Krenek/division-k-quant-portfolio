# Layer 7.1 — Synthetic Market Tracker

Layer 7.1 tracks markets that exhibit synthetic‑engine behavior.  
These markets show coordinated burst patterns, mechanical stepping algorithms, recurring ignition windows, hollow‑book displacement, and actor‑driven synthetic cycles.

This layer identifies markets where synthetic engines are active, either continuously or intermittently, and records their structural behavior.

---

## Purpose of This Layer

Use Layer 7.1 to:

- identify synthetic‑engine markets  
- classify synthetic burst patterns  
- detect stepping‑algo behavior  
- track recurring synthetic ignition windows  
- analyze actor‑driven synthetic cycles  
- correlate synthetic behavior with flat‑spike markets  
- support pattern and engine‑evolution analysis  

Synthetic markets reveal **mechanical burst families**, **actor coordination**, and **synthetic timing cycles**.

---

## What This Layer Contains

- market name  
- date and time  
- start price  
- peak price  
- movement type  
- total run length  
- synthetic‑behavior notes  
- recurrence frequency  
- extra structural notes  

Each entry represents a complete synthetic‑engine event.
