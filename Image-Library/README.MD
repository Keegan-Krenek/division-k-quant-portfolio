# Image Library README

The Division‑K Image Library is the visual archive for all structural market‑engine research. It contains screenshots, charts, fingerprints, spike clusters, timing visuals, candle sequences, liquidation events, and pattern references used throughout the Master Schema, Proto‑Database, and structural theory system.

This library acts as the visual companion to all Division‑K documentation and SQL tables.

---

## Purpose of the Image Library

The Image Library exists to:

- Provide visual evidence of structural behavior

- Support actor fingerprint classification

- Document spike clusters and ignition patterns

- Capture candle sequences across multiple timeframes

- Store liquidation cascades and recovery signatures

- Record synthetic timing sync across markets

- Provide examples for pattern ontology

- Support future dashboards and machine‑assisted tools

It is the visual backbone of Division‑K structural trading research.
